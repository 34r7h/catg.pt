## 1. What it is
**Mate Security is an AI SOC platform — an open foundation for agentic cyberdefense, built around a Security Context Graph.** It is listed as LinkedIn Top Startups 2026 — Israel #8.
- **Not to confuse with:** Material Security (material.security), a different company; this entry is Mate Security, mate.security, the Tel Aviv AI SOC company.
- **Security Context Graph:** a living model of an organization's security relationships — asset ownership, business criticality, privileged identities, and policy — built by Mate's Reason Mining engine from tables, logs, and documents.
- **AI agents:** agents use the graph as their knowledge source to investigate alerts, build detections, and respond, retaining what each investigation learns so later investigations start from institutional memory rather than from scratch.
- **Continuous Detection / Continuous Response (CD/CR):** Mate's closed-loop framework in which investigations compress into detections and detections feed the next investigation.
- **Gamebooks:** a product for governing how AI agents run investigations — teams write procedures in natural language or convert existing playbooks, and the same Gamebook keeps running when tools or stacks change.

## 2. How it is used
- When Mate integrates, it builds the context graph, and its agents then triage and investigate the alert queue, reaching evidence-based verdicts and containing threats, with detections tuned against what investigations actually turn up.
- Security teams use it for SOC investigations, detection engineering, threat hunting, and incident response, including in CI/CD and supply-chain environments.
- It is sold as working without SIEM lock-in; availability on AWS Marketplace is per the company's blog.
