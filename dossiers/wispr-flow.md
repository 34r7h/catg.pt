## 1. What it is
**Wispr Flow is an AI voice-to-text dictation tool from Wispr AI, a San Francisco startup.** It is listed as LinkedIn Top Startups 2026 — US #18.
- **System-wide dictation layer:** press a key, speak, and polished text appears in whatever app is in focus — email, docs, chat, or code editors — rather than dictating inside a single app.
- **Not verbatim transcription:** per public guides, Flow waits until the speaker finishes, then produces a polished version — removing filler words and self-corrections and formatting for the message type (email, text, and so on).

## 2. How it works
- **Languages:** per public guides, 100+ languages, including mixed-language input, plus a custom dictionary for names and terminology.
- **Command Mode:** voice editing commands, per public guides, so spoken corrections edit existing text rather than only appending dictation.
- **Platforms:** per public guides, macOS, Windows, iOS, and Android (Android described as early access in some 2026 guides).
- **Cloud processing:** per public guides, transcription is cloud-based, not offline — a trade-off for users handling sensitive material.
