# Worldcastr — distilled knowledge (from the website as of 2026-10-18)

## What it is (30 seconds)
**Worldcastr** is described as a "foundation lab for physical development" building "the benchmark, training data, and model that predict how places change." It pairs dated institutional forecasts with realized outcomes to create a time-valid benchmark, training corpus, and built-environment model. Parcel/neighborhood forecasting is the execution wedge. Worldcastr states it remains pre-revenue.

**One line for different audiences:**
- Planners/utilities/developers/lenders/investors: "Time-valid benchmark pairing what was expected with what happened next — test long-range claims against the physical world."
- Data/modeling teams: "Normalized historical forecast-outcome pairs with publication/target dates, geography, assumptions; parcel/tract/neighborhood forecasts with uncertainty ranges."
- Institutional partners: "Independent forecast validation/calibration while retaining existing consultants/planning models; add measured performance history."

## How it works / approach
- Preserve historical public forecasts with original publication date, target date, geography, assumptions, and realized outcomes.
- Create normalized forecast-outcome pairings (time-valid benchmark + training corpus).
- Serve parcel, tract, neighborhood forecasts with lower/median/upper modeled outcomes (explicit uncertainty).
- Validate against bounded cases (Arizona cited as validation wedge across 4 public forecast vintages); national normalization remains financed work.
- Production requests measure system activity (not people/customers/demand/revenue); pre-revenue.

## Key figures (as stated)
- 50M+ parcel observations
- 14M production requests each week
- ~7% one-year-ahead median error (stated)
