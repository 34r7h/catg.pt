# Chainguard — distilled knowledge

Source: LinkedIn Top Startups 2026 — US #42; chainguard.dev (official site), accessed 2026-10-29. Pages skipped: none in this distillation — listing-plus-official-site distillation, full site capture pending.

## 1. What it is
**Chainguard is the trusted source for open source — delivering hardened, secure, and production-ready builds of the open source software engineers and AI agents rely on.** It is listed as LinkedIn Top Startups 2026 — US #42.
- **The problem:** open source is the foundation of modern software, but general-purpose base images arrive with OS-level vulnerabilities, no SBOM, and no CVE remediation SLA — leaving each team to chase patches.
- **The answer:** minimal-by-construction images, rebuilt continuously from source, so teams inherit far fewer vulnerabilities and spend less engineering time on patching.
- **Customers named by Chainguard:** Fortune 500 enterprises and industry leaders including Anduril, Canva, Fortinet, Hewlett Packard Enterprise, OpenAI, Snap, and Snowflake.

## 2. The products, per chainguard.dev
- **Chainguard Containers:** minimal, zero-CVE container images, built with only what is needed to run the application, with high-quality SBOMs and verifiable signatures out of the box. The catalog covers more than 2,500 container projects, rebuilt daily from source in the Chainguard Factory, per chainguard.dev.
- **Chainguard Libraries:** the same secure-by-default model for Python, Java, and JavaScript packages, built from source in a SLSA L3-compliant factory, with a cooldown-protected upstream fallback and a proprietary malware scanner, per chainguard.dev.
- **Chainguard VMs and OS Packages:** secure VM images and 30,000+ secure OS packages and select base images, per chainguard.dev.
- **Chainguard Actions:** secure CI/CD integrations.
- **Chainguard Agent Skills:** the hardening approach applied to AI agent skills.
- **Commercial Builds:** hardened, minimal, continuously updated container images of commercial software from partners including GitLab, Elastic, F5 NGINX, Percona, Mattermost, Grafana, and others, per chainguard.dev.

## 3. Compliance posture, per chainguard.dev
- **Built-in evidence:** SLSA L3-compliant artifacts with full provenance and SBOMs, FIPS-ready images, and signed attestations.
- **Frameworks Chainguard says it supports:** FedRAMP, PCI DSS, CMMC 2.0, SOC 2, CRA, Essential Eight, NIS2, and HIPAA, through its hardened artifacts.
- **Remediation claims, labeled as Chainguard's own:** over 88,000 CVEs remediated across its customer base, with an average CVE reduction of 97.6% versus open-source equivalents — Chainguard figures, not independently verified here.
