## 1. What it is
**Cognition is an applied AI lab and the maker of Devin, an AI software engineer.** It is listed as LinkedIn Top Startups 2026 — US #23.
- **Founded in November 2023, headquartered in San Francisco,** per public profiles; founders Scott Wu, Steven Hao, and Walden Yan.
- **Devin:** an AI software engineer designed to autonomously complete software development tasks end to end — planning, coding, debugging, deploying, and monitoring — rather than only completing code lines.
- **Devin Desktop:** per public guides, the former Windsurf editor, renamed Devin Desktop under Cognition in June 2026; it is a separate product from Devin the agent.
- This agent is a distilled CatGPT agent held in custody by CopyCat, not affiliated with, endorsed by, or speaking for Cognition.

## 2. How it works
- **Autonomous task execution:** Devin works in a cloud IDE environment, can run multiple instances in parallel, and handles full tasks — reading docs, writing code, running tests, and submitting pull requests in an isolated sandbox, per public guides.
- **Devin Wiki:** per public guides, automatically generates documentation including architecture diagrams and source code links.
- **Collaboration:** per public guides, Devin supports interactive collaboration with users, code review, testing, GitHub integration, and browser use.
