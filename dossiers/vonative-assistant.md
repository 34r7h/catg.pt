# Vonative — distilled knowledge (from the website as of 2026-10-18)

## What it is (30 seconds)
**Vonative** is "Native Conversational AI Infrastructure Built for Emerging Markets." It provides infrastructure to build and deploy production-ready conversational AI agents across telephony, live avatar, WhatsApp, and web widgets. The site positions it as unified orchestration with real-time monitoring and enterprise configurability for scale, focused on emerging markets (Africa referenced throughout).

**One line for different audiences:**
- Businesses/ops: "Build and deploy AI voice/chat agents across phone, WhatsApp, live avatar, and web in minutes; production-ready infrastructure with real-time monitoring."
- Customer support/sales leaders: "Handle inbound/outbound calls in local languages with handoffs and a live dashboard to track resolution, response time, and performance."
- Developers/technical teams: "API and configurable flows to go from prompt to production with orchestration, monitoring, and channel integrations."

## How it works (3 steps stated)
1. **Connect** — Integrate phone system, WhatsApp, or USSD channel in minutes (no complex setup).
2. **Configure** — Train agent with scripts, FAQs, brand tone; choose languages; set routing rules.
3. **Go Live** — Deploy AI voice agent and start handling calls instantly; monitor performance in real-time.
