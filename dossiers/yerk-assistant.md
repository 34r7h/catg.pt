# Yerk — distilled knowledge (from the website as of 2026-10-18)

## What it is (30 seconds)
**Yerk is a macOS app for music producers** that "organizes samples, backs up every session, and moves projects between DAWs, so you can spend your time making music." It runs locally on your Mac — the sample classifier ships inside the app, uploads nothing, and never moves your original files. First build ships **November 2026** (macOS first; Windows later); preorder is **$15 one-time**, refundable until delivery.

**One line for different audiences:**
- Producers: "Stop managing files: find any sound by BPM/key/mood, keep every session hash-verified and versioned, and open an FL Studio project in Ableton."
- Collaborators/mixers: "Send a Logic session to an Ableton user — they open a session, not a folder of loose files (FL Studio→Ableton live today)."
- Privacy-minded producers: "100% local: no server receives your audio; works offline and on unreleased material."

## How it works (4 product pillars)
1. **Smart Sample Search / auto-tagging** — Point Yerk at folders/drives. It reads the file name first (only if unambiguous), then analyzes the audio (tempo, key, genre, instrument, mood) entirely on your Mac, and files an *organized library* whose folder names carry the tags — searchable in Finder, Logic/Live browsers, or any DAW. Originals stay where they were; unreadable files are listed with counts (never silently skipped).
2. **Project Conversion (DAW transfer)** — FL Studio `.flp` → Ableton Live 12 `.als`, read/written locally, instruments, patterns, tempo, sample references and mapped effects survive; approximation marks where no exact equivalent exists; third-party plugins must be installed on the opening Mac. Built from analysis of **558 real FL Studio projects**. Logic Pro, Pro Tools, Cubase "next."
3. **Version Backups** — Hash-verified versions of DAW projects (Logic `.logicx` bundles copied as bundles, Ableton, FL Studio, Pro Tools) to Dropbox, Google Drive or an external drive, on a schedule, whether or not Yerk is open.
4. **Collaborate seamlessly** — *Coming soon*: shared project work, audio/MIDI/automation intact, notes on the clip and bar (waitlist).

## Positioning (from /alternatives)
- One app instead of 3–4 subscriptions: sample organizer + converter + backup (vs Sononym, XO, Atlas, Waves Cosmos, Splice, Jukeblocks, Backblaze/Time Machine).
- vs Splice: Splice = new sounds to download; Yerk = the sounds you already own (both fine together).
- vs sample organizers: they organize inside their own browser/plugin; Yerk organizes the files so tags are folder names visible everywhere.
- vs Jukeblocks: same job, but on your Mac, nothing uploaded, alongside backups.
- vs Backblaze/Time Machine: general file copy ≠ versioned, verified, still-openable DAW project backup.

## FAQ highlights (from /faq)
- Audio never uploaded; classifier runs locally; backups go to your chosen destination.
- No file renaming/moving: organized library is separate; originals untouched.
- Backups cover Logic Pro, Ableton Live, FL Studio, Pro Tools (incl. `.logicx` bundles).
- Hash-verified = checksum of every copied file vs source; only counts when copies match; recent versions kept.
- Not a plugin; results show in Finder/DAW browsers.
- Post-launch price: **not set yet** — preorders are told launch pricing first.
