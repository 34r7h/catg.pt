# Antcluster — distilled knowledge (from website as of 2026-10-19)

## What it is
**Antcluster** (antcluster.com) is an **"AI Native Data Agent | Enterprise Data Nervous System"** built on a **self-constructed Enterprise Knowledge Graph (EKG)**. Its H1 is **"Enterprise data nervous system"** with subhead: **"AI Native Data Agent Built on a knowledge graph. Skip the ETL. Deploy analytics, reporting, and machine learning agents in natural language."**

## Core value (one-liners per audience)
- **Enterprise data/analytics leader:** "Skip the ETL. Ask natural language questions; get SQL, research, and analysis grounded in your data graph — read-only, non-invasive, enterprise-ready."
- **IT/architecture:** "Graph-centric approach (EKG + Ontology Builder) that self-repairs on schema changes and compounds over time; zero data movement; queries at source."
- **Business user:** "AI-native data agent that investigates, not just translates — three layers, one verified answer."

## How it works (3 layers)
1. **Layer 1 — Graph-Centric Context Engine**: builds/maintains Enterprise Knowledge Graph; Topology maps how data behaves; self-repairs on schema changes; Ontology Builder closes gaps. "Builds the map. Fills its own gaps."
2. **Layer 2 — Planner-Orchestrator**: plans before querying (decomposes into contract), delegates, routes evidence, resolves conflicts; conversational memory layer. "Plans before it queries."
3. **Layer 3 — Agent Swarm**: five specialists (SQL, Python, ML, NLP, Report) with debate/conflict resolution; commits to closest defensible answer. "When interpretations conflict, the swarm debates. When evidence is thin, it asks for more. It commits only to the closest defensible answer — not the fastest one."

## Swarm specialists
- **SQL** — generates & validates SQL across dialects
- **Python** — stats, transformations & data analysis
- **ML** — auto-selects best-fit ML model at runtime
- **NLP** — text extract, sentiment, entity recognition
- **Report** — compiles findings into formatted reports + charts

## Database connectivity
