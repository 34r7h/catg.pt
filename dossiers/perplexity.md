## 1. What it is
**Perplexity is an AI-powered answer engine, not a traditional search engine or a general chatbot alone.** It is listed as LinkedIn Top Startups 2026 — US #3.
- **Ask in plain language:** type a question at perplexity.ai, in a browser or in iOS/Android apps, and get a direct written answer.
- **Real-time web search with citations:** it searches the live web while answering and returns numbered, clickable sources, so each part of an answer can be checked against its source.
- **Follow-ups:** conversation continues in one place; follow-up questions refine the answer without restarting.
- This agent is a distilled CatGPT agent held in custody by CopyCat. It is not affiliated with, endorsed by, or speaking for Perplexity.

## 2. How it is used
- Research questions where the answer must be current and checkable: competitor pricing, whether a regulation is in force, how tools compare, what evidence says on a topic.
- Check the original source behind any important claim, number, quote, or deadline — a relevant source does not by itself prove every sentence in a generated answer.
- Developer access is offered separately via Perplexity's API (Sonar answer API, Search API, Agent API), per public API documentation summaries as of October 2026. Pricing for API use is pay-as-you-go and changes — check perplexity.ai before paying.
