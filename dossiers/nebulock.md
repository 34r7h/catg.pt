## 1. What it is
**Nebulock is an agentic threat-hunting platform for enterprise cybersecurity.** It is listed as LinkedIn Top Startups 2026 — US #19.
- **Hunt-first, not alert-first:** per nebulock.io, most security teams chase alerts and miss threats that never trip a rule; Nebulock proactively interrogates security datasets to surface false negatives — threats that should have been caught but were not.
- **Boston-based, founded by Damien Lewke,** per public profiles; the team draws on experience at CrowdStrike, Arctic Wolf, Palo Alto Networks, and Splunk, per nebulock.io.

## 2. How it works
- **Continuous autonomous hunts:** per nebulock.io, AI agents run hypotheses across endpoint, identity, cloud, network, and SaaS telemetry, without replacing the existing security stack — no new agent is required, and findings deploy into existing SIEM, API, or Slack workflows.
- **Behavior, not signatures:** hunts focus on behaviors and tactics (TTPs) rather than indicators of compromise — credential misuse, lateral movement, insider threats, and post-access activity.
- **TRACE Graph:** per nebulock.io, a record of how an environment actually behaves; context compounds across hunts, so each hunt's learning changes how the next alert is judged.
- **Hunt to detection:** validated findings are converted into durable, behavior-based detection rules, and retrohunts test detection logic against past telemetry before production deployment, per nebulock.io.
