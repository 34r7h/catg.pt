# Crazy Startup Guy — distilled knowledge (from the website as of 2026-10-19)

## What it is (30 seconds)
**Crazy Startup Guy (crazystartupguy.com)** is a founder community/connector brand run by Christopher Carew. It's not a SaaS product; it's a collection of links to events, WhatsApp groups, and projects. The homepage tagline: "Startups can be stressful, startups can be fun, but you must be crazy, to work on more than one."

**One line for different audiences:**
- Startup founders: "A connector hub with geo- and topic-based WhatsApp groups, Luma calendars of events, and affiliate links to related projects."
- Event attendees: "Find tech events across major US cities (NYC, SF, LA, Miami, Austin, Atlanta, Boston, Las Vegas, Chicago, DMV) and RSVP links for them."
- Community seekers: "Join curated WhatsApp groups by location, role, sector, or purpose (founders, investors, AI, etc.) via Luma RSVP links."

## How it works
1. **Explore links**: Homepage lists projects, affiliates, event calendars, WhatsApp groups, and other startups/projects.
2. **Join groups**: The WhatsApp Groups page organizes groups into Geo-based, Subject-based, Title-based, Sector-based, and Purpose-based — each entry links to a Luma RSVP page.
3. **Find events**: Luma Tech Scene Calendars page links to city-specific Luma calendars and Partiful profile. Also mentioned: Partiful (@crazystartupguy).
4. **Merch/store**: A store section exists (MFHja) with event registration passes and merch (e.g., t-shirt, GA passes for various dates) — small checkout items.
5. **Affiliates**: Dedicated affiliates page links to external projects.
